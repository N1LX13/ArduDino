# ArduDino
A small dino game for Arduino Uno with point tracking and a game over screen.

__PINS:__

OLED SCREEN:
VCC: 5V
GND: GND
SCL: Pin 5
SDA: Pin 4

JUMP BUTTON:
Pin 7
GND (no resistors needed)
